# 🧠 Daily Learning Assistant

A smart and interactive learning assistant built with **Python** and **Streamlit** to help beginners consistently improve their programming skills through daily topics, examples, and quizzes.

---

## 🚀 Features

- 📅 **Daily Topics** — Auto-displays a new programming concept each day (Functions, Loops, OOP, etc.)
- 💡 **Code Examples** — View Python code snippets for quick learning
- 🎥 **YouTube Recommendations** — Get relevant learning videos for each topic
- 🔍 **Topic Search** — Find and review content for any day
- 🧪 **Multiple Quizzes** — Test your knowledge with 2–3 questions per topic
- 🖥️ **Streamlit GUI + CLI** — Use the app with a friendly GUI or via command-line
- 📈 **Extensible** — Easily add more topics, quizzes, and features

---

## 🛠️ Tech Stack

- **Python** (OOP Principles)
- **Streamlit** (Web GUI)
- **CLI Support** (Command-line interaction)
- **Modular Architecture** (Separation of GUI, logic, and data)
